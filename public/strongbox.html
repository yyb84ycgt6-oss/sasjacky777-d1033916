Storage

Self-test

Writes a 4 MB file, encrypts it, reads it back and compares every byte, then searches what was stored for a marker it wrote into the file. Then deletes it. Nothing is faked — watch the timings move.

What this is

One page. Everything you save is encrypted on this device with a key derived from your password. There is no account and no upload: the page sends nothing anywhere, and the only thing it ever downloads is a fresh copy of itself, kept so it opens with no signal. The Checks tab counts the page's own requests to prove it.

How it protects things

PBKDF2-HMAC-SHA256, 600,000 iterations
16-byte random salt, unique per vault
AES-GCM 256, fresh 12-byte IV per write
Key held in memory only, dropped on lock
Payloads in IndexedDB, encrypted before write
Names and types encrypted too — sizes and the item count are not: the length of what is stored gives them away

Lose the password and the data is gone. That's the point of it, and there is no recovery path.

What it deliberately doesn't do

Each of these was cut because it cannot work in a web page on an iPhone, and shipping a button that pretends otherwise is worse than shipping nothing.

No local model calls. An https page cannot reach http://localhost:11434. Browsers hard-block mixed content, and "localhost" on your phone means your phone, not your PC.

No model downloads. A progress bar that isn't moving real bytes is an animation.

No bridge to another chat. A sandboxed page cannot message the assistant that generated it. No such channel exists.

No API keys in the file. Anything you paste into a page is readable by that page.

Worth knowing

Add to Home Screen. Safari can evict data from sites you haven't opened in 7 days. Installed to the Home Screen, it's treated as an app and kept. Share → Add to Home Screen. Then tap Keep storage on the Checks tab. Once it has been opened with signal, it opens without.

Safari and the Home Screen are separate. On iPhone a Home Screen app keeps its own storage, apart from Safari's. Make your vault from the icon you'll actually use — or move it: Export in one, Restore in the other.

Export is your backup. The export file is encrypted with the same password and restores anywhere. Base64 makes it about a third larger than the contents. Keep one somewhere you trust. Restoring asks for the backup's password first, and changes nothing until it checks out.

It shares its site's storage. Anything else served from the same site can reach what this page stores. Without your password that is noise — but code you don't trust on the same site could also swap this page for one that isn't. On a domain of its own, it answers to nothing else.
