# CollinSurvivalCraft (CSC)

`/craft` (also `/csc` and `/minecraft`, and **Games & Worlds → ⛏️
CollinSurvivalCraft** in the sidebar) is a block-building survival game in the
tradition of Minecraft:
survival, creative and hardcore; mining, crafting, smelting, farming; mobs,
water and lava, TNT, beds, day and night, weather; saves on the device, in a
file or in the cloud; the Nether and the End, with strongholds, End cities,
shulkers, the Ender Dragon, elytra and fireworks; a starship to the real Solar
System, at its real size (see [Space](#space)), a map of the whole Milky Way
with its couple of hundred billion stars made the same every time (see
[The galaxy](#the-galaxy)), and the real sky over the
world — the Moon's phases, eclipses, meteor showers and comets on their real
dates (see [The real sky](#the-real-sky)); 52 advancements to earn;
eighteen features borrowed from the best-loved mods (minimap, waystones,
seasons, gravestones, tameable wolves, catacombs and more — see [Mods](#mods));
thirty-seven game modes on sixteen map packs, among them Primal (after ARK:
tame, saddle and ride dinosaurs), Dead Zone (after DayZ) with four more zombie
modes, five critter modes (after Pokémon, Pixelmon and Cobblemon: catch,
battle, evolve and trade original monsters, and battle your friends), and six city and casino modes (after
the crime-sandbox games: two drivable cities with traffic, police, jobs, a
car radio and a working casino — see [Game modes](#game-modes)); and
multiplayer online, over a LAN or between tabs. It is an original
work — every texture, model and sound is generated by code in `src/craft`, so
there are no asset downloads, nothing licensed from Mojang, and the game works
offline once the page has loaded.

The same game also ships on its own, with no SAS-JACKY around it: a desktop
app for Windows, macOS and Linux, and a single `.html` file that plays from
disk. See [The solo copy](#the-solo-copy) below. It was called BlockCraft until
it was renamed; the internal names (the `blockcraft` IndexedDB database, the
`blockcraft-world` export format, `src/pages/BlockCraft.tsx`) keep the old name
on purpose, because changing them would strand every world already saved.

## Layout

```
src/craft/
  engine/   the world, independent of any screen: blocks, items, textures (painted
            procedurally), noise, worldgen, lighting, meshing, physics, mobs,
            block rules (fluids, crops, falling blocks), crafting, explosions.
            Runs in the browser, in workers and in vitest alike.
  render/   three.js: chunk meshes on a custom shader, sky, clouds, weather,
            particles, entity models, the first-person hand.
  game/     the running game: the 20-tick loop, actions (mining, placing, using),
            chunk streaming, input, commands, containers, saves, cloud saves.
  net/      multiplayer: transports (Supabase Realtime, BroadcastChannel, LAN
            WebSocket) and the host/guest session.
  ui/       React over the canvas: title, worlds, HUD, inventories, menus,
            touch controls.
  audio.ts  synthesised sound effects and music.
  edition.ts  which copy this is (SAS-JACKY or solo) and what it can reach.
src/pages/BlockCraft.tsx   the route, which configures the SAS-JACKY edition
csc/                       the solo copy: its entry, Vite config, desktop app and LAN relay
supabase/migrations/20260923120000_craft_worlds.sql   cloud saves
```

The game loop never goes through React. `Game` owns the world and the frame;
the UI reads a small store (`game/store.ts`) the game updates ten times a
second, plus on every inventory change.

## Two ways to play

**Desktop**: WASD, space, shift to sneak, ctrl or double-tap W to sprint, E
inventory, Q drop, T or / chat, 1–9 and the wheel for the hotbar, F1 hide HUD,
F2 screenshot, F3 debug, F5 camera, middle click to pick a block, double-tap
space to fly in creative. The mouse is captured while playing; every screen
releases it (see `src/test/craft-input.test.ts` for why each rule exists).

**Touch**: chosen automatically on touch devices (Options → Controls to
change). A joystick appears under the left thumb, dragging anywhere else looks
around, and buttons jump, sneak, mine and place — or "Tap to interact": tap to
place or use, hold to mine. Inventories have a quick-move toggle in place of
shift-click, and a long press is a right click.

## Redstone

`engine/redstone.ts` runs dust, torches, levers, buttons, pressure plates,
repeaters, comparators, lamps, pistons (sticky, with slime blocks dragging what
touches them), observers, daylight detectors, hoppers, droppers, dispensers,
iron doors and trapdoors, note blocks and TNT. It follows the original's rules
closely enough that circuits built from memory work: dust loses a level a block
and does not power more dust through the block it points into; a torch inverts
a redstone tick later and burns out if it is flicked more than eight times in
three seconds; a piston pushes at most twelve blocks and never obsidian, so a
slime block resting on the ground cannot be shoved sideways (it drags the
ground). Only the world's host runs it; guests see the result as block changes.

Slimes (swamps at night, and one chunk in ten below y 40 at any light) drop
the slimeballs sticky pistons and slime blocks need.

## Enchanting and brewing

`engine/enchanting.ts` holds twenty-three enchantments and the rules for
them. The table offers three enchantments, their level costs set by up to
fifteen bookshelves, and rolls them the original's way. The roll is seeded per
player, so the hint shown is what you get and reopening the table cannot
re-roll it. The anvil combines enchantments, repairs with materials or a second
copy, and renames; every job adds to the item's work penalty until it is "Too
Expensive!". An enchantment is data on the stack (`ench: { sharpness: 3 }`),
saved and sent over the network with it, and every one changes play: damage and
Smite/Bane against the undead and spiders, Protection points on top of armour,
Efficiency, Silk Touch, Fortune, Unbreaking, Looting, Fire Aspect, Knockback,
the bow's four, Thorns, Respiration, Aqua Affinity, Feather Falling and
Mending.

`engine/potions.ts` lists the potions (night vision, invisibility, fire
resistance, swiftness, slowness, healing, harming, poison, regeneration,
strength, weakness and water breathing, each with long and strong forms where
the original has them) and what brews into what; `engine/brewing.ts` runs the
stand: blaze powder for twenty brews, twenty seconds a brew. Each variant is its
own item, and each has a splash twin that bursts on whatever it hits and reaches
everything within four blocks. Healing hurts the undead and harming heals them.
Cauldrons hold three bottles of water, and hoppers feed brewing stands.
Blaze powder and nether wart come from the Nether.

## Rails, minecarts and boats

`engine/rails.ts` gives rails their ten shapes: two straights, four slopes and
four curves. A rail placed by a player joins the track around it, and the ends
it meets swing round to it. Powered rails boost a moving cart, kick a stopped one
away from a wall, and brake it when unpowered. Power runs along a line of them
for eight rails. Detector rails give a signal while a cart is on them, and
activator rails light TNT carts and throw riders out.

`engine/vehicles.ts` has the minecart, the TNT minecart and boats in five
woods. Carts run along the line between a rail's ends, a curve included, and top
out at eight blocks a second. Boats float, turn with A and D, and glide on ice.
Right-click to get in; sneak to get out. Online, whoever rides a vehicle drives
it on their own screen and reports where it went, so a guest's boat answers the
keys at once instead of a round trip later.

## Villages

`engine/villages.ts` plans at most one village per 20×20-chunk region, in
plains, desert, savanna, taiga and snowy plains, from the seed alone — so every
chunk of a village is built the same way whichever order the chunks generate
in. A village is a well and bell in a square, two to four roads out of it, and
houses along them: small and large houses, libraries and fenced farms, in the
biome's own wood or sandstone. Trees are kept off the houses and roads, and the
roads bridge water with planks.

The first time the well's chunk generates, the host settles it: a villager for
each house at its work station and an iron golem at the well; chest loot goes in
as each chunk arrives. `meta.villages` records which villages are settled, so
reloading never doubles them.

A villager takes up the trade of a free work station within eight blocks —
composter (farmer), lectern (librarian), smoker (butcher), barrel (fisherman),
fletching table, loom (shepherd), stonecutter (mason), smithing table
(toolsmith), brewing stand (cleric) or cauldron (leatherworker). One never
traded with loses its trade if its station is broken. Right-click to trade
(`engine/trading.ts`): trades earn it experience and it gains two new offers at
each of five levels; offers restock twice a day. Librarians sell enchanted books,
Mending included.

Zombies with no player to chase go after villagers, who run. Iron golems fight
monsters (never creepers) and anyone who hits them; build one from four iron
blocks in a T with a carved pumpkin on top. `/summon villager librarian` takes a
trade; online, a guest's trades go to the host, which checks the offer is still
open before it counts.

## Dimensions and the Nether

A world is one seed and three dimensions (`engine/dimension.ts`). Only the
dimension the player is in is loaded: going through a portal saves the one
being left (its changed chunks and its entities, into `meta.otherEntities`),
and `Game.changeDimension` builds the next — its world, generator, workers,
block rules, redstone and streamer — while the renderer, audio, player and
network link carry across. Chunks are stored per dimension (`n:` and `e:` key
prefixes under the world's own key range, so deleting and exporting a world
still takes everything). Dying outside the overworld respawns in it.

`engine/nether.ts` generates the Nether: caverns from 3D noise on a coarse
grid, bedrock above and below, a lava sea at y=31, and five biomes picked by
the nearest point in two climate noises — nether wastes, soul sand valleys
(soul fire, basalt pillars, fossils), crimson and warped forests (nylium, huge
fungi, vines) and basalt deltas. Glowstone hangs from the ceilings; quartz and
gold ore run through the netherrack and ancient debris hides deep where no air
touches it. Fortresses — bridges on legs over the lava, corridors, blaze
spawner platforms and nether wart gardens with a chest — are planned per
12×12-chunk region like villages; `/locate fortress` finds the nearest.

Portals (`engine/portal.ts`): fire lit inside an obsidian frame (2–21 wide,
3–21 tall, corners optional) fills it on its first tick, whoever lit it; a
broken frame lets the sheet go. Four seconds in a portal (at once in creative)
crosses over, eight overworld blocks to one Nether block. Every lit portal is
recorded in `meta.portals`, so a trip comes out of the nearest one within 128
blocks (16 in the Nether) and only builds a new one — on the nearest standing
room, or on an obsidian ledge cut into the rock — when there is none.

The Nether's rules: water boils away, beds explode, lava runs three times as
fast and twice as far, fire burns forever on netherrack, magma burns the feet,
soul sand slows. Its mobs spawn by biome whatever the light: zombified piglins
(neutral until one is struck — then all of them), ghasts (fireballs that can be
batted back), magma cubes, piglins (hostile unless you wear gold; hand them a
gold ingot to barter), hoglins, and in fortresses blazes and wither skeletons
(whose blow withers). Netherite comes from smelting ancient debris into scrap,
four scraps and four gold make an ingot, and a smithing table turns diamond
gear into netherite, enchantments and all.

Online, the party travels together: when the host goes through, every guest
follows (`dm`), waits until the host has said which chunks of the new dimension
it changed (`mk`) and where it came out (`dp`), and lands beside it. A guest
stepping into a portal alone is told that the host leads the way.

## The End

Strongholds (`engine/stronghold.ts`) lie in rings around the world's centre —
three between 640 and 1152 blocks out, more in each ring beyond — planned in
their own coordinates (portal room at the origin) and turned a random quarter.
Halls lead from the portal room to a hub, a library, a storeroom, a prison and
a fountain room, and up stairs toward the surface. The portal room holds twelve
end portal frames on a dais over lava (a tenth of them already holding an eye)
and a silverfish spawner. An eye of ender — an ender pearl and blaze powder —
thrown in the overworld flies twelve blocks toward the nearest portal room and
drops back (one in five shatters); `/locate stronghold` gives it straight away.
Set in a frame, the twelfth eye fills the ring with portal.

`engine/end.ts` generates the End on the original's plan: a height value per
column — a hundred at the centre falling off with distance, and past 1024
blocks of void a scatter of outer islands, each with its own fall-off — decides
whether there is land, how thick it is (flat tops, hanging cones) and the biome:
Highlands (hills and chorus forests, End cities), Midlands, Barrens, and the
small islands. The main island has ten obsidian spikes in a ring 42 out (two
caged in iron bars), each topped with bedrock and an end crystal, and the exit
portal's bedrock basin at its centre. Arrival is on a five-by-five obsidian
platform at (100, 48, 0), built fresh each time. The End has no sun: a fixed
half-light, distant fog, and endermen everywhere.

The fight (`engine/dragon.ts`, `game/endFight.ts`) starts on the first arrival:
the dragon circles the spikes, strafes players with fireballs that leave a
lingering cloud of breath, charges, and — the likelier the fewer crystals are
left — perches on the portal's pillar and breathes on whoever is near. A
crystal within 32 blocks heals it (the pink beam); destroying the one it draws
on hurts it. Perched it shrugs off arrows; it breaks every block it flies into
except end stone, obsidian, bedrock and iron bars. When it dies it rises for ten
seconds, then the exit portal lights, the dragon egg is laid on the pillar (the
first time — it flees a touch) and a gateway opens 96 out. A gateway (reached
by an ender pearl, or on elytra) flings a player to its far end over the outer
islands, which the generator always gives land. Four end crystals on the
portal's rim summon the dragon again. The boss bar shows its health.

End cities (`engine/endCity.ts`) stand on the highlands, grown the way the
original's are: a purpur house at the foot, then towers — each a stack of
floors with a ladder up its middle and a crown of purpur and end rods — joined
by bridges that branch into more towers, up to a dozen in a city, with loot
rooms of chests and brewing stands at the tops. Often a ship is moored off one
bridge: an end-stone hull under purpur, a dragon head at the prow, and in its
cabin an item frame holding the elytra and two chests. Shulkers guard every
level — purple boxes clinging to walls, floors and ceilings, which open to
fire homing bullets that bring levitation (an arrow off a closed shell, a
blow mostly absorbed; hurt, one may teleport to another wall) and drop shulker
shells. Two shells and a chest make a shulker box, a chest you can carry: it
keeps what is in it when broken, dyes in eight colours, and will not take
another box. Worn in the chest slot, elytra open with a jump in mid-fall and
glide by the original's formula (a dive trades height for speed, a climb
spends it; hitting a wall hurts).

The dragon is struck part by part (`dragonParts` in `engine/dragon.ts`): a
blow to the head does full damage, the neck, body and tail less, a wing a
quarter. Its fireballs leave a cloud of dragon's breath that a glass bottle
collects; breath at a brewing stand turns a splash potion lingering, and
lingering potions leave a cloud, or tip arrows. Fireworks (`engine/fireworks.ts`)
are crafted as in the original — stars of gunpowder and dyes with a shape
(fire charge, gold nugget, feather), a diamond for a trail, glowstone for a
twinkle, faded with more dyes; rockets of paper, gunpowder and stars — and fly
from the hand, a dispenser, or the air while gliding (pushing the glider,
then bursting on it). The first time a player comes home from the End after
the dragon, the poem and the credits scroll up the screen. Chorus fruit teleports its
eater; popped, it makes purpur. Endermen are neutral until looked in the eye
(or struck) — a carved pumpkin on the head hides the look — slip every arrow by
teleporting, flee water, and carry blocks about.

Online, the party travels to the End and home together as through the Nether;
gateways and pearls move only the player who used them, and the dragon's
death is everyone's advancement.

## Game modes

**Game Mode…** on the Create World screen picks one of thirty-seven modes. A
mode is a `ModeDef` in `modes/modes.ts`: the game mode, difficulty and rules
to start with, an optional map pack, and switches for what the world holds
(`fauna`, `vitals`, `engrams`, `lucky`). Modes with rounds, scores or
objectives also register a runtime (`modes/runtime.ts`). The host runs it,
once a second and on kills, deaths and respawns. It speaks to players through
a `ModeTell` (a message, a title, the scoreboard, a border, a game-mode
change), which travels to guests like any other packet and is sanitised on
arrival. Every mode that borrows from a game names it in `inspiredBy`, shown
on its card. Nothing is taken from those games except the idea: every
creature, gun, map and texture here is drawn by this game's own code.

| Category | Modes |
| --- | --- |
| Classic | Survival, Creative, Hardcore, Peaceful Builder, Superflat Creative, Void Builder |
| Minigames | SkyBlock, OneBlock, Survival Games, Wave Defense, Parkour, TNT Run, UHC, Speedrun, Lucky Blocks |
| Challenges | Random Drops, One Heart, Lucky SkyBlock |
| Primal | Primal: Survival Evolved, Primal: Survival Ascended, Primal Wilds |
| Zombies | Dead Zone, Zombie Rounds, Blood Moon, Infection, Outbreak |
| Critters | Critter Quest, Critter Craft, One-Life Run, Safari Park, Battle Spire |
| City & Casino | High Roller, Neon Bay, Golden Coast, Street Racing, Rampage, Cops & Robbers |

**Map packs** (`engine/maps.ts`) are laid over or in place of the terrain by
`MapGenerator`, so every worker builds the same map from the seed:

- skyblock, oneblock, void, parkour, colosseum, tnt_run and sg_arena.
- `primal_island`: an island in open sea, with three great obelisks.
- `dead_zone`: towns, a hospital and a military base, each on dry ground
  found by `dryNear`.
- `zombie_bunker`: a sealed bunker with buy pads, doors and boarded windows.
- `critter_region`: six towns up one road north, with a lab, four gyms, the
  League, route trainers and a summit.
- `safari_park`: a fenced park whose corners have their own critters.
- `battle_spire`: a round arena at the top of a spire over the void.
- `high_roller`: the Golden Stonk, a casino floor of slots, tables, a poker
  bar, the wheel and the Stonks terminal.
- `neon_bay` and `golden_coast`: whole cities, built chunk by chunk from the
  seed rather than stamped (see [City & casino](#city--casino-after-the-crime-sandbox-games)).

Chest loot is filled from named tables when a chunk first loads.

### Primal (after ARK: Survival Evolved and Ascended)

Ten creatures (`engine/creatures.ts`): dodo, dilophosaur, parasaur, raptor,
trike, stego, rex, brontosaurus, pteranodon and, in Ascended, the
gigantoraptor.

- **Levels.** Each is born at a wild level that scales its health and harm.
- **Knocking out.** Tranquilliser arrows, a club, fists or narcoberries build
  torpor (`dinoAi.ts`). An unconscious creature is fed its favourite food
  until tamed. The cost comes from `tameCost` and is kinder in Ascended.
- **Taming bonus.** A tame keeps bonus levels for how little it was hurt.
- **Riding.** A saddle lets you ride it, through the same mount path as
  boats and minecarts, with jump and, for flyers, pitch. Looking at any
  creature shows its level, torpor and what it eats.
- **Engrams** (`engine/engrams.ts`, the **Engrams** screen) lock recipes
  until learned with points earned per level.
- **Vitals** (`engine/vitals.ts`): thirst, and body heat from biome, time,
  weather, armour and fires. Both have HUD readouts.

### Dead Zone and the zombie modes (after DayZ, CoD zombies, 7 Days to Die)

The infected (`engine/infected.ts`, `engine/infectedAi.ts`) come in six
kinds:

- Walkers run once they have a target. Runners are faster.
- Brutes are slow, knock you back and batter through walls.
- Spitters keep their distance and spit acid.
- Screamers call every infected in earshot and raise more from the ground.
- Bloaters burst in blinding bile.

All of them hear: gunshots, sprinting and explosions call
`Game.makeNoise`, which alerts every infected in range to where the sound
came from. Under a blood moon (`Game.bloodMoon`, which also reddens the sky)
they all dig.

Guns (`engine/guns.ts`): pistol, hunting rifle, assault rifle and shotgun,
each with its own ammunition.

- A shot is an instant ray that passes grass and flowers and stops at the
  first solid block or body.
- A head hit does double damage.
- A shotgun fires eight pellets, summed per target.
- A guest's shots go through the host's attack path.

Wounds add to the vitals:

- **Bleeding** stops with a bandage.
- **A broken leg**, from a hard fall, is set with a splint.
- **Fever**, from raw meat, rotten flesh, pond water or an infected's bite, breaks with
  antibiotics.

The five zombie modes:

- **Dead Zone.** A fresh spawn with a bandage, a soda and beans. Looted
  towns and helicopter crashes. The scoreboard shows days alive and kills.
- **Zombie Rounds.** Points for kills and boards, spent on buy pads you
  crouch on: guns, the mystery box, the Tough Skin perk, doors to the other
  rooms. Power-ups drop, and rounds grow in number, health and speed.
- **Blood Moon.** A horde every seventh night.
- **Infection.** The fallen rise infected.
- **Outbreak.** An ordinary world with the infected in place of the usual
  monsters.

### Critters (after Pokémon, and the mods Pixelmon and Cobblemon)

Fifty-two original species over twelve types (`engine/critters.ts`). The
types are normal, fire, water, grass, electric, ice, earth, air, bug, stone,
spirit and dragon, and their chart follows elemental common sense. The
species include three starter lines, commons, rares, a dragon line and one
legend, and sixteen meme critters — the internet set loose in the long
grass: Dogeling and Wowdoge, Chonklet and Megachonk, Froggo and Vibefrog,
Stonkfish and Moonfin, Bonkbat and Bonkarang, Rickrock and Neverroll,
Copiumite and Hopium, and Sussling, which evolves into Susquatch only when it
is traded. Eighty-seven moves, all named by this game (Bonk, Yeet, Ratio,
Cope, Vibe Check, Emotional Damage, To the Moon…), fill their learnsets.
Evolutions come with level, or by trade. Every name, model and number is
this game's own; only the jokes are borrowed.

- **Battles** (`engine/battle.ts`) are a pure turn engine:
  - Priority first, then speed, decides who goes first.
  - Harm follows the classic shape: level, power, attack over defence, a
    same-type bonus, type effectiveness, a critical hit and a random roll.
  - Burn, poison, paralysis and sleep; stat stages; switching.
  - Experience is split between the critters that fought.
  - A trainer's AI picks the move likeliest to hurt.
- **Catching** uses the classic odds: the lower its health, the likelier,
  more so when asleep or paralysed. It takes four shake checks and five
  kinds of orb.
- **Where a battle runs.** The battle runs on the battling player's own
  machine: the party is theirs, kept in their player save as a
  `TrainerCard`, together with the box, the field guide, badges and coins.
  The world only shows the battle. The wild critter is held still, each
  side's critter comes out of its orb, and sparks of the move's type colour
  land on the target. A guest asks the host for those through the "ck"
  message (`game/critterPlay.ts`), which is checked field by field.
- **In the world**, critters are one mob kind, told apart by species; their
  models are built from body plans (`render/critterModels.ts`). The walking
  partner follows its trainer, and a big one can be ridden through the same
  path as Primal's saddles. Trainers watch the road and challenge whoever
  walks into their sight.
- **Healing stations** heal the party, sell orbs and medicine for coins,
  hold the storage box, and are where a trainer wakes if every critter
  falls.
- **Team Copium** (after the genre's villain teams) is a start-up that
  wants every critter turned into a token. Three grunts, two execs (Hodl
  Hank and Doomscroll Dana) and their CEO, Maximus Hype, stand along the
  region's routes, and one wanderer in seven is a grunt. Beating the CEO is
  an advancement.
- **Link battles and trades** (`game/critterLink.ts`) are between players,
  after the link cable. Ask from the party screen's Link tab, or with
  `/battle <player>` and `/trade <player>`; answer with the screen that
  opens, or `/accept` and `/decline`.
  - A link battle uses copies of both teams at full health, so nothing in it
    lasts but the record. It runs on the challenger's machine, which plays
    each turn once it has both players' choices and sends the other what
    happened (the "cv" message, straight to that player — the host is not
    involved). Every line names whose critter it is, so both read it true;
    a fainted critter is replaced by the next in line; there are no items
    and no experience; either player can forfeit.
  - A trade is an offer each and a yes each to the pair on the table. Each
    side hands over its critter only when it holds the other's yes to that
    same pair, so a changed offer is never taken on an old agreement. A
    traded critter keeps who caught it and earns half as much experience
    again.
  - Everything that arrives is checked as a stranger's words: every critter
    through the save sanitiser, every battle line and number clamped.
- **Keys and cheats:** P opens the party, field guide and Link tab.
  `/critter give` and `/critter wild` summon critters with cheats on.

The five critter modes:

- **Critter Quest.** The region: a starter from Professor Wren, trainers
  on every route, the rival (who picked the starter that beats yours) at
  three turns of the road, four gyms and their badges, the Champion, and
  Glaciarch on the summit.
- **Critter Craft.** Open terrain, critters by biome, trainers wandering,
  and a healing station to start a base with.
- **One-Life Run.** The Nuzlocke rules: one catch per area, and a fainted
  critter is released.
- **Safari Park.** Ten minutes, thirty Park Orbs, bait and mud, no battles.
  Rarer catches score more.
- **Battle Spire.** Three level-50 rentals and an endless line of
  challengers, with the Spire Master every seventh. The best streak is
  kept.

### City & casino (after the crime-sandbox games)

Two cities and a casino, inspired by the seaside and sunny-state crime
sandboxes and by Las Vegas, with every street, district, business, car,
song and person named by this game. Nothing from those games is copied —
their maps, code and audio are Rockstar's — only the idea of a city you can
drive, rob and get chased through.

- **The casino** (`engine/casino.ts`, `ui/CasinoScreens.tsx`) plays six
  games with the real odds: six-deck blackjack paying 3:2, single-zero
  roulette, a three-reel five-line slot tuned to return about 94.6%, 9/6
  Jacks or Better video poker, a big-six wheel, and Stonks, a crash game
  that returns about 97% at any cash-out. Money is `Player.cash`, play money
  kept in the player's save; using any machine or table opens its screen.
- **The cities** (`engine/city.ts`): Neon Bay, an island of pastel hotels,
  a glass downtown, docks and a park; and Golden Coast (San Yeeto), with
  desert motels and gas stations, a casino strip, suburbs and a beach. A city
  is a grid of avenues and streets, each lot planned from a hash of the seed
  and filled a chunk at a time through a setter clipped to that chunk.
  Street level is flat, sidewalks included, and doors are one block wide, so
  people walk in and cars do not.
- **Cars** (`engine/cars.ts`, `render/carModels.ts`) are vehicles with arcade
  handling, a body as wide as the car with its bumpers probed against the
  blocks, crash damage, burning, and explosions that spare the blocks. Nine
  models. A guest drives their own car and reports its damage to the host.
- **Traffic** (`engine/traffic.ts`) keeps right, steers at a point ahead on
  its lane, sweeps round the junction it picks, and brakes for what is in
  front of it. **Citizens** (`engine/citizens.ts`) walk the sidewalks by
  looking only at the block ahead, cross at the zebras, scatter at gunfire,
  and drop cash, which in a city goes straight to your money.
- **Police** (`engine/police.ts`): crimes add heat, shown as up to five
  wanted stars, lost a star at a time out of sight. Cops chase and, from
  three stars, shoot; cruisers drive the grid to you. A cop's hand on you
  standing still is a bust (the station, a fine, your guns); death is a
  hospital bill. The respray garage wipes the stars.
- **Jobs** (`engine/missions.ts`): four contacts with three jobs each —
  deliveries, car boosts, hits and street races — briefed in captions and
  marked in the world with columns of light. **The radio** (`engine/radio.ts`,
  `audio.ts`) writes its music as it plays, five stations of it, with a DJ
  between tunes; R changes station at the wheel.
- **The modes:** High Roller (a thousand dollars to make a million), Neon
  Bay and Golden Coast (free roam, jobs and all), Street Racing (one course a
  world, a record to beat), Rampage (three-minute rounds of scored mayhem)
  and Cops & Robbers (rob stores, bank the bag before you are caught).

## Space

A Starship (iron blocks, glass, an eye of ender and firework rockets, or
`/space` with cheats on) launches from wherever you stand, after a
countdown, into a real orbit 400 km above that same spot on Earth: 7.7 km/s
eastward, once round every hour and a half. Out there is the Solar System as
it really is, at its real size and where everything really is today — flown
under real physics, with EVE Online's orders for an autopilot.

- **The world is the Earth.** Each world sits somewhere on the globe (a
  latitude and longitude chosen from its seed) at one block to the metre, so
  a launch rises from the right spot and a landing comes down wherever the
  ship's path takes it — which is somewhere in this world, perhaps thousands
  of kilometres from home. The sky's date picks up the trip's. Return home
  lands at the launch site at once. The body you left behind is out of harm's
  way until you are back.
- **Where things are** (`space/ephemeris.ts`, tested against real events —
  the 2024 total eclipse, the 2022 lunar eclipse, the 2020 great conjunction
  and Mars's opposition, both of Halley's perihelia):
  - The planets and Pluto from JPL's Keplerian elements for approximate
    positions (Standish): good to seconds of arc for the inner planets and
    minutes for the outer ones, 1800–2050, and still close from 3000 BC to
    3000 AD. The Earth is placed off the Earth–Moon barycentre by the Moon.
  - The Moon from the largest terms of the ELP-2000/82 lunar theory, as Meeus
    tabulates them.
  - 29 moons in their planets' equatorial planes, with their real sizes,
    shapes, tilts and periods (their places along the orbit are approximate);
    Triton goes backwards.
  - Asteroids (Vesta, Pallas, Juno, Hygiea, Psyche, Eros, Bennu, Ryugu,
    Apophis, Phaethon), dwarf planets (Pluto, Ceres, Eris, Haumea, Makemake,
    Sedna, Quaoar) and comets (Halley, Encke, Swift–Tuttle, Tempel–Tuttle,
    Hale–Bopp, Hyakutake, McNaught, NEOWISE, 67P) from Minor Planet Center
    and JPL elements, the old catalogues' B1950 ones precessed to J2000.
    Periodic comets are timed between real perihelia: Halley's next is
    28 July 2061. ʻOumuamua and Borisov pass through on open hyperbolas.
  - The main belt with its Kirkwood gaps, the Hildas, Jupiter's Trojans and
    the Kuiper belt, as a few thousand representative orbits.
  - The Webb telescope at L2, and the two Voyagers heading out.
- **Real physics** (`space/newton.ts`, on the conics of `space/orbit.ts`;
  the default, switched on the ship panel):
  - *Gravity and orbits.* Only the body whose sphere of influence the ship is
    in pulls on it (patched conics, as Kerbal Space Program and mission
    planners' first sketches do). With the engine off the ship follows its
    conic exactly — Kepler's problem solved in universal variables (Vallado,
    algorithm 8), not stepped — so an orbit stays an orbit at a million times
    real speed. Crossing into a moon's sphere or out to the Sun's, its
    velocity is carried across by the two bodies' own velocities, which is
    what bends a flyby.
  - *An engine that can only push so hard.* The scout has 5 g (25 g on the
    microwarpdrive), and every order is flown against gravity with it:
    approach, keep at range and Hold spend thrust holding the ship up; the
    panel counts the Δv spent. The burns a pilot makes by hand — prograde,
    retrograde, normal, anti-normal, radial out and in — and Circularize are
    buttons; `Space` cuts the engine.
  - *Changing height the way spacecraft do.* Orbit (`W`) at the world the
    ship is at flies a Hohmann transfer: round the orbit off, burn to put its
    far side at the height asked (never below the air, or 2% of the radius),
    coast half an orbit, round it off again. The autopilot runs the clock
    through the coast.
  - *The orbit, as a flight controller reads it.* The panel gives periapsis,
    apoapsis, period and inclination to the body's equator (a launch due east
    is tilted by its latitude, as Cape Canaveral's are); the path ahead is
    drawn round the body with its highest and lowest points marked, and where
    it comes down into the air.
  - *Warp* needs the nose on the target and three seconds of spool-up, and
    drops the ship into a circular orbit where there is gravity to hold one
    (109 km over the Moon, 1.63 km/s), or holding station where there is not.
  - *The air.* Earth, Venus, Mars, Titan and the giants have exponential
    atmospheres (NASA's planetary fact sheets; the Earth's fitted to the
    50–100 km layer an entry slows in) that turn with their planets. Land (`D`)
    burns about 100 m/s retrograde to put the orbit's low point 50 km up and
    lets the air do the rest: drag and heat through the fire (a ballistic
    entry peaking near 7 g, as a Soyuz's does when it cannot fly a lifting
    one), a parachute opening over eight seconds under 10 km, 10–15 m/s under
    the canopy, and touchdown in the world where the path came down. From
    orbit it takes about a minute and a half of play; the clock runs itself.
  - *No crashes.* Anywhere without a world to land in, the flight computer
    will not let the ship fall below a safe height: it pulls up into an
    orbit and says so.
  - *The clock* runs at any speed while coasting, is held to fifty times while
    the engine burns or the ship is in the air (those are flown in
    quarter-second steps), and slows by itself near a sphere of influence so
    the ship cannot skip past one.
- **Arcade flight** (`space/flight.ts`, the other setting): EVE's rules and
  no gravity. Orders, not a joystick: approach (`Q`), orbit (`W`), keep at
  range (`E`), align (`A`), warp (`S`) to within 0, 10, 100 or 1,000 km;
  double-click space to fly that way; `M` the microwarpdrive; `Space` stops.
  Velocity closes on what the order wants exponentially, with an align time;
  warp needs the ship aligned and at three quarters of its speed, then builds
  exponentially to 5 AU/s and falls off toward the destination — seconds to
  the Moon, under twenty to Jupiter. The ship keeps station relative to
  whatever it is near, so a planet does not slide away at 30 km/s.
- **The clock** runs in real time or up to three million times faster (`,`
  and `.`), and can be set back to now; orbits, phases and comet tails follow.
- **The overview** lists planets, the moons where you are, small bodies, or
  everything, nearest first; Show Info (`I`) gives each body's facts and
  numbers — size, mass, gravity, escape velocity, day, orbit, and how long
  its light takes to reach the Earth.
- **The view** (`space/spaceView.ts`): every body drawn in its own depth
  range, far to near, so a 42-metre ship and Neptune 4.5 billion km away are
  both sharp. The sky is the real one: the 5,044 stars to magnitude 6 with
  their colours, and the Milky Way's measured outline. Worlds are painted by
  code with their real features where known — the Earth's real coastlines
  from Natural Earth, with clouds, deserts, ice and city lights on the night
  side; the Moon's seas and Tycho's rays; Mars's dark Syrtis Major, bright
  Hellas and caps; Jupiter's belts and Great Red Spot; Saturn's rings with
  the Cassini Division and the planet's shadow; Pluto's heart; Iapetus's two
  faces. Comets grow a blue ion tail and a curved dust tail inside five AU.

Sources: JPL Solar System Dynamics (planetary elements and physical
parameters), the Minor Planet Center, the IAU WGCCRE (poles and rotation),
Jean Meeus's *Astronomical Algorithms* (the lunar series); stars from XHIP
(Anderson & Francis 2012) and the Milky Way outline by Jose R. Vieira, both as
packaged by d3-celestial (© 2015 Olaf Frohn, BSD 3-Clause — see
`space/skyData.ts`); Earth's coastlines from Natural Earth (public domain).
`scripts/csc-space-data.mjs` rebuilds the sky data from those sources.

## The galaxy

**Galaxy map** in space (or `G`) opens the Milky Way: all of it, a hundred
thousand light-years across, down to the red dwarfs a few light-years from
the Sun. Drag to turn, scroll or pinch to zoom, click a star for its card,
double-click to fly the map there; `F` centres on the selection, `H` comes
home to Sol, `G` goes back to the ship. The search finds the real stars and
landmarks by name ("vega", "pleiades", "centre").

- **The real neighbourhood** (`space/nearStars.ts`): every star system
  within about thirteen light-years, where they really are — Proxima and
  Alpha Centauri, Barnard's Star, Wolf 359, Sirius and its white dwarf,
  Epsilon Eridani, Tau Ceti — and the stars everyone knows or knows of:
  Vega, Arcturus, Betelgeuse, Rigel, Deneb, Polaris, TRAPPIST-1, 51 Pegasi,
  Tabby's Star, VY Canis Majoris, Eta Carinae. Landmarks: the Hyades and the
  Pleiades, the Orion and Crab nebulae, the Vela pulsar, Cygnus X-1, Omega
  Centauri, 47 Tucanae, M13, and Sagittarius A* at the centre. Nothing is made
  up inside thirteen light-years of the Sun.
- **Everything else is made, the same every time** (`space/galaxy.ts`).
  Space is cut into cubes, big ones for the rare bright kinds and small ones
  for the common dim ones, and each cube's stars come from a generator seeded
  by its coordinates, so a star has the same name, place, colour and size in
  every world and on every machine, and can be made again from its id alone.
  How many a cube holds is drawn from the galaxy's density there, which is the
  measured one: a thin disk and a thick disk, a boxy bar and bulge 27° from
  the line to the centre, four spiral arms pitched 12° (Perseus,
  Sagittarius–Carina, Scutum–Centaurus, Norma–Outer) with the Orion Spur the
  Sun sits in, and a halo. Young blue stars keep to the arms and the plane;
  old red ones are everywhere, thickest in the bar. Here that comes to about
  a tenth of a star per cubic parsec, three in four of them red dwarfs; in
  all, about 195 billion.
- **Thirteen kinds**: O, B, A, F, G, K and M dwarfs, white dwarfs, brown
  dwarfs, orange and red giants, and blue and red supergiants, each with the
  temperature, mass, luminosity and size of its kind. Every star gets a name
  from its sector ("Morsul Crown OSX-CF"), and a card with its type, surface
  temperature, where it is and how far from Sol, where it sits in our sky,
  how many planets it probably has (the real ones say how many are known, or
  that none are confirmed) and its habitable zone.
- **Seeing it**: out past a few thousand light-years the galaxy is a cloud
  — the yellow bar, the arms with their pink nebulae, the dark dust lanes, the
  globular clusters round it. Closer in, the cloud gives way to the stars
  themselves, charted round wherever the map looks: the bright kinds out to
  thousands of light-years, the red dwarfs to a hundred. Moving the map
  charts the stars round the new spot a kind a frame, so the map never stops
  turning while it does.

Sources: the Sun's distance from the centre from the GRAVITY Collaboration
(2019) and its height above the plane from Bennett & Bovy (2019); the disks,
bar and halo after the review by Bland-Hawthorn & Gerhard (2016) and the bar's
shape after Dwek et al. (1995); the arms after Reid et al. (2019); the local
census after the RECONS survey and Reylé et al. (2021); stellar parameters by
spectral type after Pecaut & Mamajek (2013); the equatorial-to-galactic
rotation from the Hipparcos catalogue (ESA 1997). The procedural scheme —
cubes seeded by their coordinates — is the one the Elite games made famous;
the code is our own.

## The real sky

Over the overworld, the sky is the real one over the world's place on Earth
(the latitude and longitude its seed chose — the same place a starship
launches from), worked out each frame from the same ephemeris the starship
flies through (`space/sky.ts`, drawn by `render/realSky.ts`). It is one of the
mod features, **The Real Sky**, and can be switched off per world for the old
clockwork sky.

- **Its own calendar.** A world keeps a date (`WorldMeta.skyEpoch`): its first
  day is the real day it was first played, and every game day after is the
  next real day. Game noon is local solar noon. So the Moon runs through its
  phases in twenty-nine and a half game days, the planets creep along the
  zodiac, and a world played through a game year sees the real year's
  eclipses and showers.
- **The Sun keeps real hours.** It rises late and sets early in winter and
  the other way round in summer, higher or lower with the latitude, and
  daylight, sleeping and the undead burning follow it rather than the clock:
  night is when the Sun is down. A bed wakes you at the real sunrise.
- **The Moon** is lit from the Sun's side, so its phase is tonight's and its
  terminator leans the way it really does; its face is turned by its real
  pole, it goes orange low down, it lights the night by how full and how high
  it is, and in daylight it is the pale thing it is. It hides the stars
  behind it, and its dark part shows faintly in earthshine.
- **The stars** are the 5,044 real ones to magnitude 6 (and a scatter of
  fainter made-up ones, thickest along the Milky Way), turning about the pole at the right
  height for the latitude, fainter and twinkling low down, washed out by
  twilight and by a bright Moon. The Milky Way comes out only in true dark.
- **The planets** are there as the bright wanderers they are, each as bright
  as it really is that night (Mallama's phase laws for Mercury's and Venus's
  crescents): Venus as the evening or morning star, never more than 47° from
  the Sun.
- **Comets** show when they really did or will: Hale–Bopp in the spring of
  1997, Halley in the summer of 2061, each with a tail pointing away from the
  Sun.
- **Meteor showers** — the twelve major ones of the International Meteor
  Organization's calendar, Quadrantids to Ursids — rise to their peaks on
  their real dates (by the Sun's longitude), and their meteors streak out of
  their radiants at the rate the radiant's height allows; sporadic ones fall
  every night. The chat says which shower is falling, from where, and whose
  dust it is.
- **Eclipses.** The Moon's disc crosses the Sun's where it really does, seen
  from the player's own spot on the Earth (the Moon is near enough that a few
  hundred kilometres matter). The day dims only a little until the last
  sliver, and then at totality it is suddenly dusk, with a sunset all round
  the horizon, the corona and a pink rim round the black Moon, and the stars
  and planets out — and the undead stop burning. The clock slows to a twelfth
  of its pace through the deepest minutes, which at a game day's speed would
  otherwise be gone in three seconds. A lunar eclipse turns the Moon dark red
  in the Earth's shadow. Standing under a total eclipse earns **Path of
  Totality**.
- **The Sun and the Moon are drawn eight times their real size** — at half a
  degree they would be a few pixels. Near the Sun the Moon's distance from it
  is stretched by the same factor, so the drawn overlap is exactly the real
  one; away from the Sun it stands among its true stars.

`/sky` says what is up — the time, the Sun and Moon, the planets and comets
in view, the showers, and the next eclipses. With cheats on, the host can move
the sky: `/sky now` (the real sky this minute), `/sky date 2024-04-08 13:40`
(local solar time), `/sky moon full`, `/sky eclipse [solar|lunar]` (the next
one that can be seen from here, a little before it deepens), `/sky shower
perseids` (two in the morning of the peak night), and `/sky chase` — any one
place sees a total eclipse only every few centuries, so this finds the next
total (or `annular`) eclipse anywhere, moves the world under the centre of its
path, and starts the clock twenty-five minutes before totality. `/sky place
home` puts the world back where its seed had it. The date and place travel to
guests with the time; a trip into space starts on the world's date, and the
world's sky takes up the trip's date when you land.

Tested against real events in `src/test/craft-sky.test.ts`: the Sun's noon
height at the equinox, the full and new moons of 2024, 2024's four eclipses
and where the 8 April totality fell (Dallas yes, Sydney no), the greatest
points of the 2024 and 2026 total eclipses, the umbra of the 2022 total lunar
eclipse, the Perseids' and Geminids' dates and radiants, Hale–Bopp in 1997
and Halley in 2061, and Venus's greatest brightness and elongation.

Sources: the International Meteor Organization's meteor shower calendar
(peaks, rates, radiants); Mallama and Hilton (2018) for the planets'
magnitudes; the IAU WGCCRE for the Moon's pole; Danjon's enlargement of the
Earth's shadow; Jean Meeus's *Astronomical Algorithms*; eclipse dates checked
against NASA's Five Millennium Canon of Eclipses (Espenak and Meeus).

## Saving

Worlds live in IndexedDB — only chunks that were changed are stored, gzipped.
The game saves every 30 seconds, when the tab is hidden, and on quit. If
IndexedDB is unavailable (some private modes) the game says so on screen and
keeps the world in memory; export it to keep it.

The world list exports a world to a `.blockcraft.json` file and imports one
back. **Upload to Cloud** stores that same file in `craft_worlds`, owner-only
under RLS; **Cloud Worlds…** lists and downloads them on any device signed in
to the same account. The table arrives with `supabase db push` — until then
the cloud buttons say exactly that, and nothing else is affected.

## Multiplayer

The host owns the world. Esc → **Open to friends** gives a six-letter code;
friends use **Multiplayer**, type it and join. "Online" goes through Supabase
Realtime broadcast channels (`blockcraft:<code>`); "Tabs on this device" uses a
BroadcastChannel and needs no network at all. "LAN" is the solo copy's way to
play together (below): a WebSocket to a relay on the host's computer.

Guests generate untouched terrain from the seed themselves and fetch only
chunks the host reports as modified. Block edits are applied at once where they
are made, sent to the host, numbered and rebroadcast, so every client converges
on the host's order; edits for a chunk still loading are held and replayed
after it arrives. Mobs, water, time and weather run only on the host. A host
keeps ticking in a background tab (browsers stop animation frames there), and
a guest's inventory is stored in the host's world under the guest's
browser-stable id, so it is still there when they rejoin.

## The solo copy

`csc/` builds the game with nothing of SAS-JACKY around it — no sign-in, no
Supabase, no router — from the same `src/craft`. `src/craft/edition.ts` is
the seam: the `/craft` page configures the SAS-JACKY edition (the app's
Supabase client, cloud saves, "Back to Jackie"); `csc/src/main.tsx` configures
the solo one. Anything that needs a backend asks the edition first, so the
solo copy hides the cloud buttons and the "Online" link instead of offering
buttons that fail.

| Build | Command | What you get |
| --- | --- | --- |
| Desktop app | `npm run csc:build`, then in `csc/desktop`: `npm install && npm run dist` | Windows installer + portable `.exe`, macOS `.dmg`, Linux AppImage — each built on its own OS |
| One file | `npm run csc:single` | `csc/dist-single/index.html`: the whole game in one file that plays from disk, offline |
| Web | `npm run csc:build` | `csc/dist/`, for any static web server |
| Try it | `npm run csc:dev` | http://localhost:8090 |

The **CollinSurvivalCraft downloads** workflow (Actions → Run workflow) builds
all of these on GitHub's Windows, macOS and Linux machines and leaves them
under the run's Artifacts; pushing a `csc-v1.2.0`-style tag also attaches them
to a Release. None is code-signed: Windows SmartScreen says "Windows protected
your PC" (More info → Run anyway), and macOS wants a right-click → Open the
first time.

**Saves** stay on the computer, in the app's own storage (IndexedDB behind a
`csc://` scheme in the desktop app, so the origin — and every saved world —
survives updates). **Export…** and **Import…** move a world between copies,
including to and from the SAS-JACKY edition: both read the same format.

**LAN play.** The desktop app's **Open to friends → Open to LAN** starts a relay
in the app (`csc/desktop/relay.mjs`, port 25580) and shows this computer's
address and a world code; friends choose **Multiplayer → LAN (same network)**
and type both. The relay forwards messages and nothing else — the host's game
is still the authority, exactly as online — so a browser copy (the single file,
say) can join a desktop host. The first time, the host's firewall asks whether
to let the app accept connections; it has to be allowed. Any machine with Node
can run a relay by itself: `node csc/desktop/relay.mjs`, then every player
joins it with that machine's address.

**Online rooms** in the solo copy are off, since it has no server. A build
given a Supabase project — `VITE_CSC_SUPABASE_URL` and a publishable
`VITE_CSC_SUPABASE_KEY` in `csc/.env.local` — offers them again.

**Why a classic worker in the single file.** Chromium will not start a module
worker from a blob on a `file://` page; it fails after the fact, with no
message. The single-file build therefore inlines its chunk worker as a classic
script (`worker.format: "iife"` in `csc/vite.config.ts`).

## Checking a change

```
npx vitest run src/test/craft-* src/test/csc-   # engine, gameplay, input rules, cloud saves, LAN relay
npx tsc --noEmit -p tsconfig.app.json
npm run csc:single                               # the solo build still bundles on its own
```

In a development build the running game is `window.__blockcraft`, which is
how the browser checks during development read positions and screens.
