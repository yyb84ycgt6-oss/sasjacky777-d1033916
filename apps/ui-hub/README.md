# UI Hub — Cursor-Inspired Web IDE

A web-based interface for the Jackie OS system, featuring:

- **Sidebar Tools**: Quick access to router health, agent registry, pod/backpack manager, state viewer API.
- **Chat Panel**: Integrated with `JackieRouterClient` for natural language interaction with agents.
- **File Explorer**: Browse and manage files in your workspace (including the permanent vault on E:).
- **Context-Aware Routing**: The UI automatically routes requests to appropriate agents based on task type.

This hub is designed to be modular, extensible, and fully compatible with the underlying Python engine layer (`Jackie/core/engine/`).
